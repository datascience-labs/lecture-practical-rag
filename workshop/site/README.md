# 단계별 RAG 실습 웹사이트

01–12 자료를 브라우저에서 학습하는 정적 웹사이트다. 필수 실습에는 API 키, Python 패키지 설치, 모델 다운로드가 필요 없다. 모든 원문은 저장소의 가상 기업 퍼플델타 데이터다.

## 실행

저장소 루트에서:

```bash
python3 workshop/site/build.py
python3 -m http.server 8765 --directory workshop/site/dist
```

`http://localhost:8765`를 연다. `index.html`을 파일로 직접 열면 자료를 불러올 수 없으므로 HTTP 서버를 사용한다. 배포된 정적 사이트에서는 Python도 필요 없다. Sites의 소스 저장소만 받았다면 `dist/`는 생성된 데이터를 포함하므로 해당 폴더를 바로 정적으로 서비스할 수 있다. `build.py`의 데이터 재생성은 원본 Practical RAG 저장소 구조에서 실행한다.

## 구현 범위

- 회차별 목표·개념 설명·따라 하기와 12종 실습.
- 필수 설정을 모두 실행하고 원문을 확인한 후 객관식·코드 빈칸 채점.
- 코드 직접 입력 또는 같은 식의 카드 선택. 오답 힌트·재시도, 시도 횟수와 도움 여부 기록.
- 실습 기록 + 필수 2문항 통과 후 다음 회차 개방. 이미 통과한 회차는 복습 가능.
- localStorage 진도·미제출 초안·종합 실습 저장. 자료 버전별로 분리.
- 개인 기록, JSON 결과 제출 파일, 같은 버전 기록 가져오기. 가져오기 시 현재 기록 대체를 확인하고 선행 회차·답을 재검증.
- 종합 실습 3문항과 출처 열람. 작성 완료와 강사 검토 완료를 구분.
- 좁은 화면용 가로 회차 목록과 세로 실습 배치, 키보드 포커스·입력 라벨.

RRF·코사인 유사도·필터·청킹·지표·그래프 탐색·지정 점수 정렬은 브라우저에서 실행한다. 임베딩 벡터·검색 후보·관련도 점수·모델 답변·커뮤니티 리포트는 **강사 작성 교육용 예제**로 화면에 표시한다. BGE·BM25·cross-encoder·LLM·ChromaDB 서버를 실제 실행한 결과로 제시하지 않는다. 실제 모델 품질이나 지연시간·비용을 측정하지 않는다.

## 운영상 경계

이 버전은 개인 브라우저에서 진행하는 학습 도구다. 학생 간 진도 집계, 중앙 제출, 서버 자동 채점, 로그인과 강사 권한 관리는 포함하지 않는다. 정답이 클라이언트 데이터에 있으므로 시험용 부정행위 방지 기능은 없다. JSON 결과는 파일로 제출하고 강사가 종합 답변의 근거·선택 이유를 검토한다. 화면의 '작성 완료'는 수료 승인이 아니다.

새 Sites는 소유자 전용으로 배포된다. 수업 참가자용 접근 공개는 별도 공유 설정이 필요하다. 로컬 실행 또는 정적 파일의 별도 호스팅도 가능하다.

## 파일과 수정

| 파일 | 역할 |
|---|---|
| `../questions.json` | 회차·시간·문항·정답·힌트 원본 |
| `build.py` | 원문 42개와 문항을 `dist/course.json`으로 생성 |
| `dist/app.js` | 화면·채점 연결·진도·결과 파일·종합 실습 |
| `dist/labs.mjs` | 실습 조작·교육용 예제·개념 설명 |
| `dist/core.mjs` | 계산·코드 채점·완료 조건 |
| `dist/style.css` | 반응형 화면 |
| `.openai/hosting.json` | 연결된 Sites ID와 정적 배포 경로 |

문항이나 원문을 수정하면 `build.py`를 다시 실행한다. 질문·원문의 해시가 변경되면 저장 버전도 변경되어 이전 진도와 분리된다. 현재 문항 수·선택지 구조를 변경하면 `labs.mjs`의 설정과 코드 카드도 함께 검토한다.

## 검증

```bash
node --test workshop/site/core.test.mjs
node --check workshop/site/dist/app.js
```

화면 흐름의 DOM 테스트는 개발용 의존성 `linkedom`을 사용한다. 배포 페이지에는 의존성을 포함하지 않는다.

```bash
cd workshop/site
npm install
npm run test:dom
```

브라우저에서의 최종 시각 확인 항목: 데스크톱·모바일 폭, 모든 설정 실행, 원문 열기·닫기, 오답·힌트·재시도, 코드 카드 전환, 다음 회차 해제, 새로고침, 결과 다운로드·가져오기, 종합 실습 작성. DOM 테스트는 실제 브라우저의 레이아웃·키보드·다운로드 동작 검증을 대체하지 않는다.
